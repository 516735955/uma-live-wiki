# 历史文件归档

本目录保存仍有追溯价值、但不参与当前网站运行和数据生成的旧文件。当前站点入口是仓库根目录的 `赛马娘LIVE相关.html`，运行数据位于 `data/`。

## 目录说明

- `live-page-snapshots/`：2026 年 8 月 4 日至 5 日的单文件页面备份，以及角色页签注入前的快照。当前页面已拆分为 HTML、`uma_tools/app.js` 和 `uma_tools/app.css`，并包含这些快照之后加入的路由、数据加载和页面功能。
- `legacy-pedigree/`：旧版独立血统页及其配套数据。现行血统功能由主站角色页和 `data/pedigree_data.js` 提供；现行关系数据为 1334 条，旧关系文件为 1251 条，旧角色数据为 161 至 171 条，均已被覆盖范围更大的现行数据取代。
- `maintenance-snapshots/`：一次性诊断或旧生成结果。`gen_voice_part_v2.json` 的 222 条记录已被 `data/voice_participation.json` 的 262 条记录完整覆盖；另外两个文件只记录当时的封面请求状态和目录扫描失败结果，不是数据源。

归档页面按原始内容保留，内部相对资源地址不再维护，不应作为站点入口部署。
