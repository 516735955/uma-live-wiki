# 内容规范

本规范适用于站点的目录、详情和新闻。展示以来源能够确认的事实为准。先判断栏目在页面中的作用，再选择内容、状态或省略。

## 内容状态

| 状态 | 统一文案 | 使用场景 |
| --- | --- | --- |
| `uncollected` | 尚未收录{subject} | 缺字段、空记录、状态未知或尚未取得来源 |
| `not_announced` | 官方尚未公布{subject} | 官方来源明确说明尚未公布 |
| `not_published` | {subject}未公开 | 来源明确说明资料未公开 |
| `not_applicable` | {subject}不适用 | 资料类型决定该内容不适用 |
| `confirmed_none` | 已确认没有{subject} | 有明确依据确认该事实不存在 |
| `loading` | 正在加载{subject}… | 请求或资料处理正在进行 |
| `error` | {subject}加载失败 | 当前请求失败 |
| `filtered` | 没有符合条件的{subject} | 已取得数据，当前搜索或筛选无匹配项 |

资料事实可在实体的 `content_status` 中按栏目保存。明确的事实状态记录来源 `source_url` 和核实日期 `checked_at`。请求状态由页面管理。现有内容在刷新期间继续展示，首屏加载、请求失败、缺资料和筛选无结果各用对应状态。请求失败优先显示错误，可重新读取时提供重试。清除搜索或筛选会清除相关条件并返回第一页。

页面复用 `content-state`。普通状态使用紧凑的一行说明，`subject` 沿用栏目名，如「曲目」「创作资料」「演出记录」。`retry` 和 `clear` 对应可执行的操作，`reason` 只说明该栏目特有的已确认事实，例如「该录音为纯音乐，无歌词」。

## 页面层级

- **站点入口**　已开放的资料库保留导航。旧实体地址和栏目链接继续解析，并保留原页面语境与返回位置。
- **核心栏目**　核心入口随实体保留，资料缺失时在栏目内说明。明确不适用的栏目可省略，旧链接显示具体原因。歌曲全部录音明确为纯音乐时省略歌词入口。
- **补充模块**　有内容时展示标题和内容。缺内容时整个模块省略。读取失败且可恢复时，在对应位置提供重试。
- **字段**　核心身份字段保留名称及缺失状态，可选字段按实际内容展示。紧凑表格用「—」表示缺值，图片缺失时使用相应占位图或文字封面。

## 各库的展示

| 页面 | 内容规则 |
| --- | --- |
| 歌曲 | 收录、创作、歌词、出演记录为核心栏目。创作信息展示有署名的版本。动画关联按实际内容展示。 |
| 专辑 | 曲目是核心栏目。空列表按 `content_status.tracks` 显示状态。已有曲目照常展示，播放操作对应实际有音源的录音。 |
| 角色与声优 | 身份资料、歌曲、动画出演与活动出演使用稳定入口。角色的血统入口依据明确的原型映射。 |
| 动画 | 作品和单集分别组织角色、职员、音乐与观看入口。栏目依据原始可用资料生成，筛选仅影响当前结果。 |
| 活动 | 场次和阵容按实际资料展示。曲目块随已有歌单出现。取消场次保留公告及已有出演资料，曲目块省略。 |
| 创作者与制作人员 | 身份资料为核心，歌曲、合作和作品关联按具体署名及参与范围展示。 |
| 原型马 | 身份资料为核心，简介、生涯、成绩、比赛、荣誉和退役资料按事实展示。 |
| 新闻 | 正文是核心。原文、译文、归档状态和读取失败分别展示，中文缺失时显示「尚未收录中文译文」。 |

## 时间、身份与关联

- **活动与场次**　父活动页承载活动身份、总日期、地点及系列。场次选择器位于页首，使用实际场次名和日期，已有取消状态同步显示。场次详情使用本场的简介、阵容、媒体和曲目。旧场次链接打开父活动并选中对应场次。
- **演出时间**　显示统一的日期与时间。日本时间的 24:00 及以上归入实际次日。动画以首播或首发为主，其他渠道单独展示。资料精度为日期时只显示日期。
- **出演身份**　现场曲目和阵容区分以马娘角色出演、以其他身份出演的马娘声优和其他人员。声优履历标明非马娘身份出演。歌曲出演记录聚焦赛马娘角色。历史记录按父活动归组，保留实际出演场次的标签和链接。
- **音乐录音**　录音版本和发行分别保存。同一录音可关联多张专辑，作品用途按片头曲、片尾曲和插曲等实际使用范围展示。作品级资料与单集资料保留各自的证据和范围。作品归属和发行系列分别用于检索。
- **音源**　播放操作对应具体录音。播放器显示实际音质和试听状态，音源确认前显示目标档位。唱片资料、发行封面和站内音源各自判断可用性。
- **场地**　已确认的同一场地共用一个 `venue_id` 与统一展示名。不同厅和不同巡演城市分别记录。线上播出和待定地点使用对应的文字状态。
- **搜索**　目录使用共享检索规则。搜索、排序和筛选通过 URL 恢复，前进、后退和实体跳转保留对应语境。

## 来源与中文

来源原文、中文译文与人工订正分别保存。中文沿用站内统一的角色、声优和作品译名，正式日文名称、原署名与歌词按原样保存，可并列已核实的中文。自动更新按稳定来源身份和字段合并，人工订正优先。新增或原文实质变化的文本才进入翻译，已归档译文直接读取。图片、标题和正文均归属于各自的来源记录。
