# 自用音乐播放与资料补齐方案

2026-11-09。状态为待确认。方案以当前线上 `main` 的 `f5b80985` 为基线，正式实施时重新核对播放权益、发行状态和缺项。现阶段交付方案与路线图登记。

## 现状和目标

粉丝站用于个人使用，不对外推广或商用。已确认资料页继续匿名访问，不增加整站登录。站主希望现有播放器能使用自己的会员权益播放完整录音，并按实际来源选择音质，同时希望打开网站就能播放。线上歌曲页目前在无登录时返回 HTTP 200，部署配置也没有给现有播放 API 配置站主校验。若匿名播放接口调用同一个会员会话，拿到链接的人也能使用该会话的播放权益。GitHub 和部署凭证的存放位置与播放接口的可访问范围分别处理。

- 当前有 116 张专辑、2,253 条专辑曲目、1,042 首作品及 2,172 个录音版本。未填音源的 774 条专辑曲目中，745 条集中在 18 张活动限定盘，17 条属于已有网易云专辑 ID 的 4 张发行，4 条属于其他已发行内容，8 条是当时尚未发行的《WINNING LIVE 37》。
- 已登记的 1,479 个网易云曲目 ID 中，1,478 个在本次匿名查询中返回与录音时长一致的元数据。跨 31 张专辑的线上抽样返回完整大小的音频。《BRIGHTEST HEART》确认线上实际返回约 30 秒的 MP3，原录音约 4 分 03 秒。整库元数据核验与线上抽样分别统计。
- 15 条曲目缺专属图片。7 条可使用《WINNING LIVE 36》的正式专辑封面，8 条随《WINNING LIVE 37》正式封面发布补齐。现有 76 张远程专辑封面本次均返回图片，实施时再核对解码与图片归属。[36 官方发行](https://umamusume.lantis.jp/discography/winning-live-36/) · [37 官方发行](https://umamusume.lantis.jp/discography/winning-live-37/)

## 一、用现有播放器完成个人会员播放

1. **MUSIC_U 是登录会话的核心字段。** Songuesser 旧 Python 后端用 pyncm 的 `LoginViaCookie`，当前 Android 版已经改成设备直接连接网易云。Android 将凭证放在设备端加密存储，用 `/weapi/song/enhance/player/url/v1` 请求指定音质并读回实际档位。项目实测仅发 `MUSIC_U` 的请求曾被视为匿名，所以还会携带网易云用于识别客户端的会话参数。取音频时，同一个会话只用于需要凭证的网易云 API 或经核对的网易云音频 CDN。
2. **网站复用现有服务。** Android 原生网络层能自己设 Cookie，网页脚本和音频标签没有这个能力。建议把会话配置在已有 Wiki 服务的非公开运行目录，由当前 Node 服务的播放后端解析音源并处理拖动所需的 Range 请求。无需新服务器或让 Mac 常开。Git、发布包、浏览器、公开接口和日志都不包含网易云会话；会员播放不走第三方 Meting 镜像，也不接受任意上游地址。历史 pyncm 实现用作参考，优先验证 Lyric Desk 的现有解析方式或最小等效适配。[浏览器请求头限制](https://developer.mozilla.org/en-US/docs/Glossary/Forbidden_request_header)
3. **访问方式仍需确定。** 网易云付费会员协议把权益限定为订购账号自行使用。站主专用的会员播放可以走已有私人设备或网络访问方式，若没有，再决定是否接受只在个人播放入口做一次轻量验证。资料页和匿名可播放音源继续直接打开。匿名访客使用站主账号播放会员音源的要求目前未纳入可实施范围；如有平台明确允许的播放或嵌入方式，再作为候选。无登录页面也可继续使用平台提供的试听与官方发行链接。[网易云付费会员协议](https://y.music.163.com/m/at/prime-membership-contract?fromRN=1)
4. **先验证账户、音质和完整音频。** 在受限环境用《BRIGHTEST HEART》、普通完整录音、Game Size 和有真实无损档位的样本，核对现有线上主机能否稳定解析、拖动并播放到曲尾。Lyric Desk 在 Mac 上读 Keychain，其本地成功记录不能代替线上验证。会话失效时由站主重新同步，匿名可用的来源继续播放。遇到仅试听、另购、下架或地区限制，保留实际状态和正式发行入口。临时失败保留上次已核验的资料和人工订正。

## 二、补齐录音、封面和音质

- 优先修复已确认的试听误判，再处理 21 条有发行线索的缺项，逐张核对 18 张限定盘，已发售才重查未发行队列。用正式品番、盘号、曲序、演唱者、录音版本和时长核对；保留同名独唱、合唱、现场和 Game Size 的独立关系。记录未找到数字发行、仅试听、账户不具备播放权限、源站临时失败和未发售等原因，交付各状态的数量和剩余清单。
- 封面优先补确有官方图的曲目，曲目没有单独封面时继承同一发行的正式专辑图。增量采集允许正式封面替换占位图，保留已核验的原图和图片归属。
- 首期默认「自动」，提供实际可用的「标准 128 kbps」「高音质 320 kbps」「无损」。前两档已在两首歌的匿名接口样本上实测；两首请求无损或 Hi-Res 时均返回 320 kbps MP3。无损只在该账户、该录音返回真实无损且浏览器可播放时出现。切换音质保持队列、录音、进度和播放状态，降档显示实际档位。Hi-Res 和空间音频留待有真实曲目和设备样本再加。
- 现有播放动作、底部播放器、持久队列和歌词数据继续使用。批量入队不把已知试听当整曲。保留现有录音、专辑、歌词时间轴、角色、歌单及其备注注释；只对同一录音补充来源、播放状态与封面。

## 三、可随本批收口的路线图事项

- 建议一起完成音乐条目下与本次共用来源的数字发行补录、平台地区和失效状态，以及本域媒体缺项复查。限于现有歌曲目录涉及的发行，不扩张到全站通用采集。
- 可选把歌词同步高亮、定位当前行、点击跳转一起交付。现有歌曲页已能读取录音对应的逐行时间轴，页面还未连接播放器时间。只在当前录音有匹配时间轴时启用；更换音质不换时间轴，切换录音时使用相应版本，保留现有歌词与译文入口。
- 完整播放器页、独立歌词阅读页、扩充现场编曲与演职署名、全站日历搜索，以及并行的原型马与赛事资料库仍按各自路线图推进。

## 验收

- 用未登录窗口验证个人接口、直链、Range、过期会话都不能取到个人会员音频。站主登录后用桌面与手机验收完整播放、拖到曲尾、连续播放、清晰的试听状态和音质切换。
- 以《BRIGHTEST HEART》《BLOW my GALE》《うまぴょい伝説》《ゆるゆるSAMBA》、一张多盘 Solo Vocal 和《WINNING LIVE 36／37》覆盖权限、版本、已有缺项、图片继承和未发行状态。
- 核对更新只改变有新证据的音源和图片字段，既有人工资料与歌单不被覆盖。比对线上与本地受影响的目录和录音，分别列出已验证的完整播放、试听、无数字发行、未发行和源站暂不可核实的数量。凭证或上游会话失效时，验收站主提示和现有可用播放的回退路径。
