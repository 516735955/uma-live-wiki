# 赛马娘演出综合站路线图

## 现有范围

站点以演出、音乐和作品为入口，关联活动场次、现场歌单、歌曲录音、专辑、动画作品与单集，以及角色、声优、创作者和原型马。音乐播放器提供播放队列和音源支持的音质。原型马档案包含身份、成绩和血统资料。

## 重点方向

### 原型马与竞赛档案

- 以已登场原型马为中心，补齐生涯赛绩、主要成绩、赏金、荣誉、图片与中文资料。覆盖地方及海外赛事。
- 建立赛事、具体比赛、赛马场、赛马人物、牧场与现实俱乐部的详情及互链。人物页按骑手和调教师身份组织内容。
- 比赛页展示完整赛果、参赛马、赏金和负重。已登场原型马连接现有档案，其他参赛马通过资料卡呈现基础信息、亲缘和繁育关系。
- 收录赛事成就、年度表彰和殿堂马荣誉，保留构成赛事及获奖依据。关联经过核实的动画单集与正式比赛回放。
- 牧场记录公开近况、历史安置与官方见学信息。马主、厩舍和训练基地在马匹档案内作为字段展示。

### 音乐与演出资料

- 补充可核实的数字发行与音源，重点覆盖《WINNING LIVE 24》、活动限定盘，以及《WINNING LIVE 37》发售后的录音。
- 补录正式影像盘、特殊现场编曲、乐队和其他制作署名，完善音乐在动画、游戏和正式影像中的使用记录。
- 完善活动场次的演出信息、正式媒体、票务与物贩时间，扩展巡演路线、阵容和曲目变化的查看方式。
- 利用现有歌词和时间轴提供播放同步高亮、当前行定位与点击跳转。

### 中文资料与来源覆盖

- 补充活动简介、人物公开资料和原型马说明中的中文，复用既有术语、人工订正及归档译文。
- 扩展正式作品、唱片发行和活动来源，补齐后公布的阵容、影像、署名与单集资料。
- 完善失效链接、停更渠道、来源差异和缺项的复查，保持原文、中文和证据的对应关系。

### 关联探索

- 通过共同歌曲、活动、作品、比赛与原型亲缘查找两位角色的关联，说明每条关系所属的语境及来源。
- 利用角色、原型马、赛绩和荣誉资料制作猜马小游戏。
- 提供同场记录、交手矩阵、共同对手和可追溯的关联路径。

## 资料范围

内容聚焦赛马娘企划及其直接相关的作品、演出、音乐和现实赛马。现实马匹与作品角色分别建档，人物资料聚焦公开的企划参与。历史赛果作为资料收录，牧场和场地的访问条件以核实过的官方信息为准。

主办方、制作方、发行方和官方作品资料用于核对活动、署名与发行。竞赛结果以赛事机构记录为依据，血统和马匹身份以公开登记资料为依据。各领域的字段和维护入口见[数据说明](../data/README.md)。
