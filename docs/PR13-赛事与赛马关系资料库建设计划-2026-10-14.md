# PR13 赛事与赛马关系资料库建设计划

日期：2026-10-14。阶段：页面与内容规划；已确认的范围按本文执行，栏目排版细节继续讨论。

#13 以已登场赛马娘的原型马为中心建设真实赛马资料。页面使用“骑手／赛马场／俱乐部”标准名称，搜索兼容骑师、竞马场、俱乐部／集团、原文名称和其他已知别名。赏金只存在于马匹与比赛资料。马主永久作为原型马字段，不建设目录或原子页；厩舍与训练基地同样只作为马匹字段。

已确认建设赛事三级浏览、牧场、骑手、精简调教师、现实俱乐部及集团、赛马场。原型马详情和新增详情全部复用歌曲／角色页的栏目 Tab，不采用整页连续堆叠分节。人物照片、场地与牧场照片、俱乐部标志和有来源的胜负服图纳入首批。日文说明、字段与图片说明提前翻译为中文，保留来源原文供核对。

## 1. 新增页面与原子页

新增赛事、牧场、调教师、俱乐部、赛马场五个目录，完成现有骑手入口。独立原子页有赛事、具体比赛、牧场、骑手、调教师、俱乐部、赛马场七类；原型马沿用现有页面并改成 Tab 布局。

### 1.1 共用页面结构

目录复用本站搜索、下拉、筛选、整行记录与分页。主导航维持 DESIGN.md，入口归入“资料库 → 其他”。俱乐部统一作为导航名称，内部类型区分现实赛马俱乐部与经营集团；作品队伍、家族和玩家社团不收录。

详情从面包屑进入紧凑 Hero，再通过一套栏目 Tab 切换正文。身份、少量核心事实、官网和主要来源入口常驻 Hero。切换只展示当前栏目，栏目状态写入 URL，支持直接分享和浏览器返回。复用歌曲／角色页的吸附身份栏与栏目行为，保留筛选、分页和返回位置。

栏目名、表格、关系列表、图片网格、正文与链接采用一致格式。图片栏目使用同一套原图查看器和来源说明；单图仍可查看原图。没有实际内容的可选栏目不呈现，避免靠空栏目和大量占位文字补足页面。

### 1.2 赛事目录与赛事原子页

目录检索中文、日文、英文、正式名称和历史别名，筛选地区、主办体系、级别、芝／泥地／障碍、距离及关联原型马。长期赛事与普通单次比赛分开组织。变化中的条件注明年份，举办地不能直接代替主办体系或马匹所属。

赛事采用“赛事目录 → 赛事资料与历届比赛 → 具体比赛”的三级浏览。Hero 展示赛事名、地区与简短定位。栏目为：

- **资料**：创设、正式名称、名称由来、竞赛条件、在赛季中的位置和重要沿革，正文为中文。
- **历届比赛**：日期、年份、当年赛马场、级别、距离、冠军与骑手，点击进入具体比赛。
- **关联赛马娘**：由实际参赛记录连接角色与原型马，显示参赛年份和名次。
- **关联动画**：汇总具体比赛与动画单集的已确认关系，标明比赛年份，双向跳转。
- **图片**：有明确来源的赛事照片或正式资料图，说明年份与内容。

距离、举办地、级别、年龄条件、名称和赏金保留当年事实。NAR 的泥地体系在 2024 年发生调整；France Galop 的凱旋门赏沿革记录过异地举办和距离变化，现行条件不覆盖历史比赛。[NAR 赛事体系](https://www.keiba.go.jp/dirtgraderace/newroad/)、[France Galop 赛事沿革](https://www.france-galop.com/fr/content/historique-du-prix-de-larc-de-triomphe-le-moment-de-verite)

### 1.3 具体比赛原子页

Hero 展示中文赛事名、日期、届次或比赛编号、赛马场、当年级别、距离、芝／泥地、天气与场地状况；未知字段保留未知，不从年份或惯例推造。栏目为：

- **赛果**：完整已取得名单、正式名次、马名、骑手、负重、时间、着差、受欢迎度与赔率；每匹马可展开通关顺序、马体重、调教师、赏金及有来源的胜负服资料。
- **关联动画**：动画作品、版本与第几集，链接单集页；动画页反向链接该比赛。关系依据保存在资料中，不加入作品解读、改编分析、漫画／游戏章节或剧透模块。
- **图片**：比赛照片、正式结果或相关资料图，中文说明与原始来源并列。

首批纳入受欢迎度与赔率，保证列宽、数字对齐和标签可读。桌面优先完整扫描主要赛果，次要字段按行展开；手机固定保留名次与马名，其余字段在行内展开或局部横向滚动。完整列组合与首屏密度通过实际宽表和手机样本确认，不靠缩小正文塞入全部字段。

保留并列、取消、除外、未完成、降着和失格等正式结果。完整赛果包含无赛马娘角色的参赛马：显示名称、赛果与来源，不自动为其新建详情页；已有马匹页面可继续使用。原型马附角色入口，名单默认保持正式名次顺序。[JBIS 1990 年有马纪念结果](https://www.jbis.or.jp/race/result/19901223/106/09/)

马主不设置比赛页面的独立展示字段或人物入口。正式结果来源可以保留原始资料，不据此扩建马主页。

### 1.4 牧场目录与原子页

目录搜索正式名称和历史名称，筛选地区及已确认职能。Hero 提供牧场名、地区、简短介绍、官网和来源入口。栏目严格收敛为：

- **资料**：牧场本身的历史、地区、生产／育成／繁殖等职能、已确认经营主体和简短沿革。
- **关联赛马娘**：只列有已确认角色映射的原型马，显示生产、育成、种牡马站、历史安置等关系及时间，链接角色与原型马。
- **见学**：官方公开的见学项目名称、项目内容、对象或预约方式、官网／案内所入口、适用期间和核验日期。已结束项目按历史介绍表达，不作为当前可预约项目。
- **图片**：牧场、建筑、景观和与已登场赛马娘原型有关的照片，中文说明与来源完整。

牧场正文不扩展全体生产马、种牡马、繁殖牝马和子嗣目录。官方照片保留必要现场背景，不把背景马匹逐一新增为关系条目。个人生产者、牧场品牌、经营法人与物理设施分别识别；登记生产者字段不直接充当牧场名称。[JBIS 小栗帽档案](https://www.jbis.or.jp/horse/0000177650/)、[Northern Farm 公司资料](https://www.northernfarm.jp/company/)

历史承继在资料中说明。例如 Lake Villa Farm 官方记载其承继旧目白牧场土地和繁殖牝马，已故原型马的历史联系与当前可见学对象分别表达。[Lake Villa Farm 历史说明](https://www.lakevillafarm.com/about/history/mejiromcqueen/)

见学项目按项目官方说明和竞走马故乡案内所核对。普通牧场不采用统一的“联系牧场”按钮；公开项目有指定预约方式时链接其正式入口。赛马娘官方引导先向案内所确认并避免直接联系妨碍牧场经营。[官方牧场见学说明](https://umamusume.jp/visitingstables_guidelines/)、[案内所见学流程](https://uma-furusato.com/guide/plan)

### 1.5 骑手目录与原子页

标准名称为“骑手”，既有 /database/jockeys 地址继续可用，搜索兼容“骑师”和“騎手”。目录支持姓名、读音、所属、历史／现役状态和关联原型马检索。Hero 展示照片、中文姓名与主要身份。栏目为：

- **资料**：人物简介、生日、出身、骑手生涯与历史所属，正文为中文。
- **关联赛马娘**：只列其实际骑乘的赛马娘原型马，展示有来源的搭档时期和代表比赛。
- **骑乘记录**：仅汇总这些原型马的相关比赛，支持年份、马匹、赛事与结果筛选。
- **图片**：有来源的人物及相关比赛照片。

公开的企划活动以已有活动组件放在资料内，不另建泛娱乐人物履历。本站相关骑乘记录与完整生涯纪录保留各自范围；页面不展示人物赏金或马匹赏金汇总。“主战骑手”须有明确依据，不按一次骑乘推断。同一人转任调教师时保持统一人物身份。[JRA 人物资料](https://www.jra.go.jp/datafile/meikan/)

### 1.6 精简调教师目录与原子页

调教师已确认建设精简页面，只有人物资料、关联赛马娘与照片三个内容方向，复用骑手人物布局。栏目为：

- **资料**：中文人物简介、公开的生日、出身、任职与退役节点、照片和官方入口；信息多少可变化，字段结构保持统一。
- **关联赛马娘**：只列有角色映射的管理马匹，显示已确认管理时期与原型马入口。
- **图片**：人物照片及与相关原型马有关的可靠照片。

资料只介绍本人必要的生涯事实，不扩展全体管理马、合作网络、完整比赛目录、人物赏金或专门的作品人物原型分析。厩舍和训练基地仍放在马匹字段，不成为调教师下属独立页面。

JRA 的藤泽和雄退役介绍提供生日、出身地、免许年份、所属、照片和管理马资料，可以支持统一人物档案；历史与地方人物的缺项通过其他可靠公开来源补齐，未取得不编造。[JRA 2022 年退役调教师介绍](https://www.jra.go.jp/special/2022_intaitrainer/)

### 1.7 俱乐部目录与原子页

标准导航名为“俱乐部”，内部区分现实赛马俱乐部和经营集团。目录搜索正式名、品牌、别名与地区。Hero 展示标志、中文名、类型、短介绍和官方入口。栏目为：

- **资料**：组织的赛马职能、名称、历史和已确认相关组织，说明品牌、运营法人与登记马主法人之间的实际关系。
- **关联赛马娘**：只列有角色映射的原型马，标明登记所有、俱乐部运营、生产或育成等关系。
- **图片**：正式标志及与该组织、相关原型马有关的可靠图片。

不扩建个人马主页、全体募集马、全集团赛绩和赏金汇总。已确认法人马主属于某俱乐部时，可在原型马的俱乐部字段链接组织页；马主字段本身仍只展示事实。

Silk Horse Club 与登记马主法人 Silk Racing 职能不同，保留各自身份与有来源的关系，不能把品牌名直接替换为马匹历史登记马主。[官方组织说明](https://www.silkhorseclub.jp/beginner/mechanism/)

### 1.8 赛马场目录与原子页

标准名称为“赛马场”，搜索兼容“竞马场”和原文名称。目录支持名称、地区、国家、历史状态与场地类型检索。Hero 展示照片、名称、地区、简短定位与官网。栏目为：

- **资料**：场地本身介绍、历史和重要改建，正文为中文。
- **赛道**：有来源的赛道图，芝／泥地／障碍、左右回、内外圈、距离、直线、高低差及适用时期。
- **相关赛事**：已收录长期赛事和具体比赛，标明历史举办时期。
- **关联赛马娘**：曾在此参赛的原型马，显示实际比赛入口。
- **图片**：场地、看台和赛道照片，中文说明与原图查看。

赛道只作为场内模块，不新建赛道、厩舍或训练基地页面。现行赛道图与历史版本分开，不能用当前图解释所有年代比赛。原始图内文字保留，图注与字段解释为中文。[JRA 东京赛马场赛道资料](https://www.jra.go.jp/facilities/race/tokyo/course/)

## 2. 现有数据与模块更新

### 2.1 资料基础与关系范围

本地已有 172 匹马、168 匹有逐场赛绩、3429 条马匹赛绩记录。166 匹有马主文本、165 匹有生产者文本、167 匹有调教师／厩舍文本、171 匹有赏金文本，farm 字段尚无非空值。数据数量表示已有输入，不证明独立比赛数量、完整生涯或已确认实体数量。

在与现有角色 ID 有映射的 167 条马匹记录中，仅去除空格得到 118 个马主原始文本组和 121 个调教师原始文本组，两者各有 95 个组只对应一匹马。这些文本包含别名、历史顺序和所属后缀，尚不是规范实体数量。原始 Sunday Racing 中英文名称被分成不同组；少量调教师字符串只有“海外”，需要核对。

调教师有跨原型马聚合价值，例如本地同一藤泽和雄文本组关联 6 匹原型马，伊藤雄二文本组关联 5 匹；最终管理关系以正式资料核实。马主的个人、法人、组合和俱乐部身份差异按字段保存，不因此建设页面。[JRA 马主登记形态](https://jra.jp/owner/howto/faq/)

保留既有 horse ID、角色映射、别名和血统节点。新增赛事、比赛、人物、牧场、俱乐部与赛马场身份按明确来源整理。牧场、俱乐部、骑手和调教师关系列表只聚合有角色映射的原型马；血统原有亲本及已收录历史马匹继续保留，完整赛果不触发额外扩库。

### 2.2 比赛与参赛记录

个人赛绩按明确来源比赛 ID、日期、赛马场和竞赛编号整理为统一比赛，每匹马的参赛记录归属该比赛。只有年份、简称或主要胜利摘要的记录不生成精确日期或比赛身份。普通新马／未胜利比赛不全部归并成一个长期赛事。

正式名次、骑手、当时调教师、场地条件和赏金保留场次语义。结果采用正式来源；不同来源保留范围与依据。GI、GII、GIII、JpnI、JpnII、JpnIII、J-GI 等当年级别分别保存，移除以其他年份近似资料推测当年级别的展示方式。

现有摘要可保留为中文简介，已经解析到比赛身份的条目增加具体比赛入口。原型马赛绩与具体比赛互链，动画对应只连接明确比赛。

### 2.3 原型马页面改为栏目 Tab

复用歌曲／角色的分栏结构，Hero 保留照片、中文及原名、生日精度、性别、毛色、角色入口与少量关键事实。正文栏目建议：

- **资料**：中文简介、竞赛生涯、退役、繁殖和表彰；马主、调教师、厩舍、训练基地等为档案字段。
- **赛绩**：逐场记录、年度汇总与赏金。赛事、赛马场、骑手和已收录调教师可点击，马主不提供站内人物页入口。
- **血统**：复用已有血统图与明确亲本关系。
- **关联动画**：列出有证据的动画单集与比赛，双向跳转。
- **图片**：原型马照片、可靠胜负服图及相关正式图片，保留来源与原图。

马主仅存在于马匹档案字段，保留历史姓名、法人名称和已确认持有顺序；起止日期未知时不生成日期。冠名和胜负服属于马匹资料或图片，不组成马主介绍页。厩舍与训练基地只保存有来源的中文字段，可附来源链接。

角色页通过既有 profile 与 pedigree 入口连接原型马，保留现有 profile、songs、anime、events、pedigree 命名。不为每种现实关系新增角色栏目。#12 的分页、按需详情和血统功能继续使用。

### 2.4 赏金只用于马匹与比赛

标准用词为“赏金”，没有独立页面或排行榜，没有骑手、调教师、马主、牧场与俱乐部的赏金模块。

马匹显示总赏金、年度、中央／地方／海外分项与逐场赏金；具体比赛显示有来源的当年赏金额度及各马匹实际取得额。来源只有合并金额时不反推分项。总赏金与收得赏金分别解释，说明保留在字段附近，不另建术语页。[JRA 赏金制度](https://www.jra.go.jp/owner/members/prize/)、[JRA 收得赏金定义](https://jra.jp/kouza/yougo/w541.html)

金额保留币种、性质、统计范围、日期和来源。未知与零分开，来源总额与已收录逐场合计分开；海外保留原币种和来源换算，不直接相加不同币种。历史金额不按现行赏金表重算。

### 2.5 中文内容与媒体

#13 所有说明性正文、表头、固定字段、地名、职务、生涯描述、见学项目、图片说明与关系说明以中文展示。正式姓名使用可靠中文写法，日文和英文原名作为并列检索资料；无通行译名的专名按来源确认中文表达，不靠模糊近似合并。

采集后在维护流程中预翻译，复用 ROADMAP 与 #12 的共享术语、固定字段词典、翻译缓存、数字核验和人工精调。原文与译文分别保存，自动更新不覆盖人工中文；来源变化后重新核对相关译文。页面只读准备好的中文，不打开页面后串行等待翻译。

首批内容验收包括整段自然程度、名称、日期、金额、距离与单位。翻译失败保留已有中文和原始资料并继续补齐，未译完成的日文不视为中文内容完成。站外来源及正式照片保留原貌，页面标题、图注与解释提供中文。

人物照片、牧场和赛马场照片、俱乐部标志、胜负服图均纳入首批采集与展示。图片来源、拍摄或适用年份、图片身份和中文说明与对象对应；标志不冒充人物照片，历史照片不冒充当前状态。没有可靠照片时使用已有姓名字章或文字布局，不制造事实图片。

### 2.6 动画关联与现有活动

现有 RTTT 三条 depicts_race 关系分别连接 1999 年皋月赏、日本德比和菊花赏。新增站内具体比赛入口，保留原外部赛事身份、原始依据和反向单集关系。

已有真实赛马场活动、骑手嘉宾和牧场／俱乐部合作继续连接活动库；不为填充页面虚构企划参与。冠名竞走和现场出演活动各有记录，以明确关系连接。

### 2.7 更新流程与建设顺序

沿用 Python 采集与生成、文件资料、Node API 和零构建 Vue，复用 sync_knowledge.py 的增量、失败恢复、缺项回补和现有共享 I/O。人工订正优先；来源失败继续提供最后可读资料。新栏目按需加载，切换返回不丢失位置。

#12 负责现有原型马加载、模块拆分、缓存、发布和公共恢复；#13 负责新增业务实体、关系、来源适配、中文内容与页面栏目。接入以当时完成的接口为准，不并行重做相同职责。

建设顺序为：

2. 使用 RTTT 三场比赛贯通动画与赛果；小栗帽验证中央／地方赛绩；目白资料验证牧场历史和见学；Silk 验证俱乐部与法人关系。

验收运行真实来源解析、生成、API 和浏览器；桌面检查长表和图片，手机检查栏目换行、数字列、展开与原图操作。验证部分结果、并列与失格、历史条件、中文金额、译文更新、来源失败与返回状态。规划不新增基线、冻结契约或门禁。
